## 酒馆内安装

发布者将本目录内容上传到 Git 仓库后，使用者打开酒馆「扩展」→「安装扩展」，粘贴该仓库的 HTTPS 地址，安装后刷新页面。`manifest.json` 必须在仓库根目录。无需安装 Node.js 或运行构建。

单击悬浮球打开插件；酒馆扩展设置中的 **玲画师设置** 是备用入口。已通过 Git 安装的用户可以使用酒馆的扩展更新按钮。

账号入口：打开插件 → 顶部或左侧 **用户中心**。这是主工作区的独立页面；未登录时提供登录、注册和游客浏览，登录后可修改昵称、修改密码和退出登录。修改密码需输入当前密码，成功后使用新密码重新登录。升级后请完整刷新或重启酒馆，在「关于」核对版本 **0.11.4**。

正文出图：电脑双击 AI 回复的正文，手机在同一位置快速连点三次，在点击处旁边打开两页菜单，自动避让屏幕边缘。「图片生成」直接串联 LLM 出标签和 NovelAI 出图，不需打开设置大窗或开启全局自动生图。第一页还有视材准备、角色/服装设计；第二页有人设生成、删除非锁定图片、锁定/解锁所有Tag、收集楼层信息和正文收集。操作绑定被点击的回复。角色/服装、人设支持生成候选、审阅编辑和保存；收集支持范围、编辑、复制与导出。视材准备支持镜头/素材计划、配置导出和首帧图片，尚未接入视频渲染服务。单击已生成图片打开管理。手势默认开启，可在「流程」关闭。

## ZIP 手动安装

酒馆的「安装扩展」接收 Git 仓库地址，不接收 ZIP。将 ZIP 中的整个 `st-novelai-image` 文件夹解压到酒馆 `public/scripts/extensions/third-party/`，确认路径为 `third-party/st-novelai-image/manifest.json`，刷新酒馆。

## 首次配置

1. 打开「NovelAI 连接与参数」，选择浏览器直连并填写自己的 Token，或使用酒馆已有的 NovelAI 凭据。
2. 保存配置，先测试连接，再按需测试生成一张图片。真实生图可能消耗额度。
3. 使用「LLM 出标签」时，另行设置自己的 API 地址、Key、模型和上下文路由。
4. 默认手动出图。需要自动出图时，在「创作 → 流程 → 出图触发」选择「自动出图」并保存配置。新正文完成后，已有标签直接出图，没有标签时先用 LLM 提取；也可将出图流程设为仅使用已有标签。自动流程不弹需求确认窗。

独立 LLM 出标签只读取当前 AI 回复中最后一个完整 `<content>…</content>` 内的剧情正文；历史聊天、用户消息、标签外的思维链及防截断内容不会发送。此用途忽略历史消息数，`{{上下文}}`、`{{context}}`、`{{lastUserMessage}}` 为空；正文宏只引用当前正文。首次使用先在酒馆生成一次剧情，已有正文可直接出标签。没有完整正文时会停止请求并提示。

0.9.6 同时过滤世界书及宿主宏（包括不同大小写的 `{{lastMessage}}` / `{{lastCharMessage}}`）重新带入的整段回复。更新后完整刷新酒馆，在「创作 → 正文与图片」展开「LLM 正文预览」确认范围，再点「LLM 出标签」；无需另开过滤选项或导入显示正则。「消息原文」仍保留思维链用于编辑，不代表 LLM 请求内容。任务入队后在原位置显示进度、错误及取消入口；手机聊天图片按原比例占满文本容器，旧图片无需重新生成。

上下文条目编辑页和 LLM 预设详情在同一页显示全部条目，直接向下滚动；详情保留按名称与内容搜索。画廊顶部将搜索、新建和上传放在紧凑的横向工具栏中。

直连密钥保存在当前浏览器、当前酒馆站点的本地存储中，刷新后自动读取。它们与插件设置分开保存，不随预设导出；可在密钥输入框旁清除。浏览器禁止存储时仅本次页面有效。发布包不附带发布者的账户、密钥、聊天、图片缓存或测试配置。

默认正文标签为 `image###英文提示词###`。需要在阅读时隐藏标签，可在酒馆「扩展」→「正则」导入 [配套规则](regex/novelai-hide-image-tags.json)，保留「仅影响显示」勾选；详见 [正则说明](regex/README.md)。

预设库默认直连 `https://api2.chimeapi.com/presets`，可以在设置中修改地址；原官方地址自动迁移，自定义服务器保留。

画廊保持图片列表，点击图片查看详情。通过顶部「用户中心」或画廊「登录 / 注册」创建用户名账号；游客可浏览、查看详情和下载，登录后才能上传预设、画师串、创建分享链接和点赞。投稿仍需管理员审核；点赞位于详情，可再次点击取消。密码不写入插件配置，登录会话在当前酒馆的浏览器会话内保留。忘记密码请联系管理员重置。

画廊提供「新建空白画师串」「新建空白 LLM 预设」，无需先下载其他人的预设。「上传预设 / 投稿」支持选择本地档案或不超过 1 MiB 的 JSON；提交后等待管理员审核，审核通过才公开。上传前请移除连接配置、密钥和私人信息。署名由服务器按登录账号填写，本地效果图不会自动随投稿上传。

画师串和 LLM 预设页面均提供「云端导入（分享链接）」和「本地导入（JSON 文件）」。前者粘贴云端分享链接，后者选择电脑或手机里的 JSON 文件，兼容原版、本插件及 positivePrompt/negativePrompt 数组格式。同名预设另存新名称，导入 LLM 预设同时绑定正文出标签路由，保存配置后生效。
